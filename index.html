    Como é feita a verificação?

    O navegador não pode ler sempre o código HTTP de outro site (CORS). Se puder, o estado é certo (Online / Offline). Se não puder, tentamos um pedido no-cors e um ping por imagem: se o servidor responder, o estado é Provavelmente online; se nada responder, Provavelmente offline (pode ser a tua rede ou um bloqueador). O tempo “≈” é aproximado. Datas de commit vêm da API pública do GitHub (só repositórios públicos), em cache durante 6 h.
